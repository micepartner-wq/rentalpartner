## 워터마크 동작
- 적용 대상(새로 올리는 이미지만): 상품 대표, 추가 이미지, 상세설명 이미지, 설치사례, 패키지 설치사진, 홈 후기 슬라이드.
- 적용 안 함: 후기 사진(고객 작성), 배너·CMS·게시판, 회원가입 서류.
- 가로 400px 미만 이미지, GIF·SVG는 원본 그대로 올림. 실패해도 원본으로 올려 업로드는 막히지 않음.
- 이미 올라간 이미지는 바뀌지 않음. 워터마크는 이미지에 합성되어 저장되므로 한번 올리면 지울 수 없음(원본 파일은 따로 보관).

2. **배포** — `npm run deploy:prod` (필요하면 `firebase login --reauth` 후). 배포 후 "배포했어 확인해줘"
3. **배포 후 직접 확인**
   - 관리자 → 상품 관리 → "상품 품질 점검" 메뉴로 실제 진입, "채우러 가기" 동작
   - 상품 이미지를 새로 올려 우측 하단 로고가 들어가는지(PC·모바일)
   - 모바일 하단 상담 바가 다른 버튼과 겹치지 않는지
4. **상품 품질 채우기** — 점검 목록 기준 필수 항목 부족 69개 상품(한 줄 소개 63개, 상세 설명 37개). 점수 낮은 순으로.

## 알려진 한계 / 후속
- 운영 상태 표시는 공휴일을 반영하지 않음(평일 공휴일에 "상담 가능"으로 보일 수 있음).
- 홈에 `<h1>`이 4개(히어로 슬라이드별) — 기존 문제, 정리 권장.
- 기존에 올린 이미지에 워터마크를 일괄 적용하는 기능은 없음(원하면 별도 작업, 원본 백업 후 진행 권장).
- 우클릭·F12 차단은 효과 대비 고객 불편이 커서 하지 않기로 함.

## 정정 (같은 날 후속): 워터마크 방식 변경
- 이미지 파일에 로고를 합성하는 방식은 **철회**했다. 합성했던 이미지 483장은 백업 원본(`backup-originals/`, git 제외)으로 모두 복구했고, 서버 파일이 백업과 일치함을 확인했다. 업로드 시 자동 합성 코드도 제거했다.
- 대신 화면에서 상품·설치 사진 칸의 **우측 하단**에 로고를 덧그린다(`components/ui/ImageLogoMark.tsx`): 상품 카드, 상품 상세 대표 이미지, 설치사례, 패키지 설치사진.
- 사이트(관리자 제외)에서 이미지 **우클릭·끌어서 저장**을 막는다(`components/ImageProtection.tsx`). 글자 선택·복사는 그대로.
- 한계: 덧그린 로고와 우클릭 차단은 이미지 파일 주소로 직접 받는 것을 막지 못한다. 상세설명·후기 본문 이미지에는 로고가 없다.
- `backup-originals/`(약 770MB)는 지우지 말고 다른 곳에도 복사해 둘 것.
