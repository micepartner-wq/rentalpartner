# 설치후기 사례 작성 틀

설치후기를 "우리가 실제로 해낸 일"로 보이게 하는 공통 틀입니다. 관리자 > GNB 섹션 관리 > 게시글 등록(설치후기)에서 입력합니다.

## 화면 표시 방식 (먼저 알아 둘 것)
- 본문은 **일반 텍스트**입니다. 줄바꿈은 그대로 유지되지만 굵은 글씨, 제목 서식, 표는 지원하지 않습니다.
- 그래서 소제목은 `■`처럼 눈에 띄는 기호로 시작하는 한 줄로 씁니다.
- **사진은 본문 위의 "본문 이미지 업로드" 버튼으로 넣습니다.** 커서가 있는 위치에 삽입되므로, 해당 설명 바로 아래에 커서를 두고 올리세요.
- 본문에 쓴 `http(s)://` 주소는 자동으로 링크가 됩니다.
- **괄호 안의 안내 문구와 모르는 항목은 반드시 지우세요.** 쓴 그대로 사이트에 공개됩니다.

## 입력 칸별 작성법

| 칸 | 쓰는 법 | 예시 형식 |
|---|---|---|
| 제목 | `장소/행사 + 핵심 숫자`. 검색에도 쓰입니다 | `국가기술자격시험장 PC ○대 설치` |
| 한줄 요약 | 1~2문장. 목록 카드에 노출됩니다. 숫자를 넣으세요 | `시험장 ○실에 PC ○대와 모니터를 설치하고 시험 종료 후 회수까지 진행했습니다.` |
| 카테고리 | 기존 카테고리 중 선택 | 시험장 / 사무실 / 행사 등 |
| 대표 이미지 | 현장이 가장 잘 보이는 사진 한 장 | |
| 본문 | 아래 본문 틀 | |

## 본문 틀

```
■ 고객 유형
공공기관 / 기업 / 행사 주관사 중 해당하는 것

■ 현장 상황
언제, 어떤 공간에서, 무엇이 필요했는지 두세 문장으로

■ 구성 장비와 수량
- 장비명 ○대
- 장비명 ○대

■ 일정과 지역
설치 ○월 ○일 · 운영 ○일간 · 지역 ○○

■ 설치 과정
1) 사전 확인: 
2) 반입과 설치: 
3) 점검: 
4) 회수: 

■ 해결한 문제
어려웠던 점 → 어떻게 풀었는지

■ 결과
사실만 적기 (고객 반응은 실제로 들은 말만)
```

## 작성 원칙
1. **사실과 숫자만 씁니다.** 수량, 일정, 지역은 정확한 값을 확인한 것만 적고, 모르면 그 항목을 통째로 지웁니다.
2. **고객 동의를 먼저 받습니다.** 고객사 이름, 현장 사진, 수량은 공개 허락을 받으세요. 공공기관은 `○○기관`처럼 익명으로 적어도 됩니다.
3. **과장하지 않습니다.** `최고`, `업계 1위` 같은 비교 표현은 근거가 없으면 쓰지 않습니다.
4. **같은 틀을 지킵니다.** 사례끼리 비교하기 쉬워야 고객이 "우리 상황과 비슷하다"고 읽습니다.
5. **중요한 사례부터** 3~5개를 먼저 제대로 쓰고, 나머지는 시간이 될 때 채웁니다.

## 사례 하나를 맡길 때 알려 줄 것
사진과 함께 아래를 알려 주면 틀에 맞춰 문구를 만들어 드립니다. 모르는 항목은 `모름`이라고만 적으면 됩니다.
- 고객 유형 / 장소 / 행사명(공개 가능한 범위)
- 장비와 수량
- 일정, 지역
- 설치 중 어려웠던 점과 해결 방법
- 고객이 실제로 한 말(있다면)
