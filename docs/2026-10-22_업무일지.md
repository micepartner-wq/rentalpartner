- **결정(질문 후 확정)**: 상품 미지정 문의는 DB의 전용 항목 1개에 연결, 화면은 기존 폼 + "필요한 장비·수량" 직접 입력.
- **구현** `pages/QuoteRequest.tsx`: 장바구니가 비어 있으면 빠른 모드(필요 장비 입력칸). 접수 시 `bookings.product_id`가 NOT NULL이라 시스템 상품 `QUICK-QUOTE`(`product_type:'place'`, 고객 목록에는 안 나옴)에 연결. 요청 메모에 `[필요한 장비·수량]`이 들어감. 장바구니 로딩 중 빈 화면이 깜빡이지 않도록 `cartLoaded` 가드 추가.
- **견적문의 화면 상품 삭제 버튼** 추가(항목별 삭제, `confirm` 확인).
- DB: `add_quick_quote_product.sql` 제공(**실행 여부 확인 안 됨**, 앱이 없으면 만들도록 되어 있는지 직접 확인 필요).
- **검증 못 한 것**: 실제 제출 후 이메일 도착, 관리자 목록 표시.

## 2) 패키지/상품 데이터 정리 (운영 DB 직접 수정, 요청에 따라)
- 컨퍼런스 올인원 패키지 구성품 `120인치 대형 스크린` → `100인치 대형 스크린`.
- 사진 속 `+` 위치가 상품과 어긋난 5곳 좌표 수정(이전 값 → 새 값):
  - 기업 화상회의: (49.66,33.49) → (83,33)
  - 공공기관 보고·회의: (60.03,11.74) → (48,21)
  - 국정감사: (62.26,16.33) → (50,26)
  - 컨퍼런스: (76.99,13.3) → (65,24)
  - 스마트 임시 사무실: (26.5,63.21) → (37,74)
- 태그 → 구성품 연동 규칙, 상품 대표 이미지 여러 장(갤러리) + 관리자 크롭, 상세 설명 이미지 확대 보기(저장 방지)는 이전 작업분 포함.

## 5) 안드로이드 APK (스토어 등록 없이 직접 설치)
- **이유**: 홈 화면에 설치(PWA)가 폰에서 안 되고, ERP 서버처럼 APK로 쓰고 싶다는 요청.
- **방식**: Capacitor로 사이트를 감싸는 껍데기 앱. 프로젝트는 **레포 밖** `C:\Users\USER\Desktop\Rentalpartner-android`(appId `kr.rentalpartner.admin`). 시작 주소 `https://rentalpartner.kr/login`, 사용자 에이전트에 `RentalAppAndroid` 추가.
- 파일은 `public/app/rentalpartner.apk`(약 4.4MB, 디버그 서명)로 사이트에 올려 `/install`의 **앱 다운로드** 버튼으로 받게 함. 안드로이드·PC는 다운로드 버튼, 아이폰은 사파리 "홈 화면에 추가" 안내.
- **앱 동작**: 로그인 → 메인 사이트(`/`). 앱에서는 "로그인 상태 유지"와 "아이디 저장"이 기본 체크, 이미 로그인돼 있으면 로그인 화면 건너뛰고 메인으로 이동(`pages/Login.tsx`). 일반 웹 로그인은 그대로.
- **아이콘 문제와 원인**: 첫 APK는 아이콘 앞 레이어에 기본 Capacitor 그림이 남아 로고가 안 보였음 → 앞 레이어를 직접 생성(로고 66%, 배경 `#edf4fc`)해서 해결. 로고가 너무 커서 잘리는 문제도 66%로 줄여 해결(사용자가 폰에서 확인: "크기 괜찮아").
- **빌드 주의**: `./gradlew assembleDebug`만 하면 낡은 빌드가 나온 적이 있어서(1초 만에 끝나고 크기 동일) `clean assembleDebug`로 다시 만듦.
- 설치 페이지의 "안드로이드·아이폰 모두 가능" 배지는 **확인하지 않고 넣은 문구**여서 삭제.
