# 2026-10-15 업무일지

## 1) 설치후기 사례 작성 틀
- 설치후기를 "실제로 해낸 일"로 보이게 하는 공통 틀을 `docs/설치후기_사례_작성_틀.md`로 만들었습니다. 본문 소제목은 ■ 기호로 시작하는 고정 항목(고객 유형, 현장 상황, 구성 장비와 수량, 일정과 지역, 설치 과정, 해결한 문제, 결과)입니다.
- 본문은 일반 텍스트(서식 없음)로 표시되고, 사진은 "본문 이미지 업로드"로 커서 위치에 넣는 방식이라 코드 변경 없이 쓸 수 있습니다.
- 사례마다 사진과 사실(수량, 일정, 해결한 문제)을 받아 이 틀에 맞춰 문구를 작성하기로 했습니다. 모르는 항목은 지어내지 않고 뺍니다.
- 이후 사례 구조가 자리 잡으면 전용 입력칸(DB 컬럼 추가)으로 바꾸는 방안은 보류입니다.

## 2) 패키지 설치사진 `+` 버튼 정렬
- `+`가 글자로 그려져 폰트에 따라 원 안에서 치우치던 것을 CSS 선 두 개로 바꿔, 항상 원 정중앙에 오게 했습니다. 선택 상태에서는 `−`로 바뀝니다.
- 파일: `components/products/PackageInstallationGallery.css`
- 검증: 개발 서버에서 버튼 4개를 직접 띄워 크기(30×30)와 중앙 정렬, 선택 상태 전환을 확인했습니다. 실제 패키지 상세 화면에서는 확인하지 못했습니다.

## 3) 상품 상세 "상세 상단 이미지" 크기
- 사진이 여러 장일 때 한 줄에 3장(모바일 2장)으로 작게 보이던 것을, PC와 모바일 모두 한 줄에 1장(전체 너비)으로 바꿨습니다.
- 확대 갤러리는 만들다가 요청에 따라 되돌렸습니다.
- 파일: `components/products/ProductInstallationCases.tsx`
- 미검증: 타입 검사만 통과했고 실제 화면에서는 보지 못했습니다. 사진이 많으면 페이지가 길어집니다.

## 4) 패키지 기본 구성 ← 사진 태그 연동
- 관리자 패키지 편집의 "기본 필수 구성품" 칸에 **사진 태그로 덮어쓰기** 버튼을 넣었습니다.
- 설치사진에서 "기본 포함"으로 찍은 상품으로 구성품 목록을 통째로 바꿉니다(기존 목록은 사라지며, 실행 전 확인창에 새 목록이 보입니다). 수량은 한 사진 안의 같은 상품 태그 개수이고, 여러 사진에 나오면 사진별 개수 중 최댓값입니다. "추가 선택"과 "연출 참고"는 제외합니다.
- 고객 화면과 저장 구조는 그대로입니다(구성품은 계속 상품 이름으로 연결).
- 파일: `pages/admin/ProductManager.tsx`, `src/utils/installationScenes.ts`
- 검증: 타입 검사 통과, 수량 계산 규칙을 가짜 데이터로 확인했습니다(TV 2·1개 → 2, 의자 1·3개 → 3, 추가 선택과 연출 참고 제외).
- 미검증: 관리자 화면에서 버튼을 눌러 덮어쓰기와 저장까지 한 흐름은 아직 해보지 못했습니다.

## 5) 환경
- LAN 개발 서버를 다시 열었습니다(`localhost:3000`, `192.168.35.242:3000`).

## 남은 이슈 / 확인 필요
- 덮어쓰기 버튼은 누른 시점의 태그만 반영합니다. 태그를 나중에 바꾸면 다시 눌러야 하고, 실행 전 현재 구성품의 수량을 기록해 두는 편이 안전합니다.
- 홈 설치후기 슬라이드 4개(세미나/회의실, 기업 사무실, 국가기술자격시험장, 박람회/행사부스)는 이미 운영 DB(`home_review_slides`)에 등록되어 있어, 배포해도 홈 후기 구역은 그대로 보입니다(10월 15일 DB 재확인).
- 운영 DB에 옛 `home_review_pins`(빈 배열)가 남아 있습니다. 동작에는 영향이 없습니다.
