# 2026-10-14 업무일지

## 1) 개별 상품 "상세 상단 이미지" + 관련 패키지 자동 연동
- 일반 상품 상세페이지(상세정보 탭)의 상세 이미지 바로 위에 이미지를 최대 6장까지 넣을 수 있게 했습니다.
- 이미지 아래에 "이 상품이 포함된 패키지" 카드를 자동으로 보여줍니다. 패키지 설치사진에서 이 상품을 +태그로 연결해 두면 관리자가 따로 설정하지 않아도 연결됩니다. 여러 패키지에 태그돼 있으면 모두 나옵니다.
- 이미지 아래에 고정 문구를 넣었습니다. 연결된 패키지가 있으면 "연출된 이미지입니다. 자세한 내용은 아래 패키지 상품에서 확인하실 수 있습니다.", 없으면 "연출된 이미지입니다."입니다.
- 고객 화면에서는 "설치 사례" 같은 제목과 이미지 설명 텍스트를 뺐습니다. 관리자 화면 이름도 "상세 상단 이미지"로 통일했고 설명 입력칸은 없앴습니다.
- 상세 설명이 비어 있어도 위에 이미지가 올라가 있으면 "상세정보를 준비중입니다" 박스를 숨깁니다. 설명도 이미지도 없으면 박스가 그대로 보입니다.
- DB: `add_product_installation_cases.sql`을 새로 만들었고 Supabase에서 실행까지 마쳤습니다. 구 DB에서는 이미지 없는 상품 저장이 계속 되도록 호환 처리를 넣었습니다.
- 바뀐 파일: `src/utils/installationCases.ts`, `components/admin/InstallationCasesEditor.tsx`, `components/products/ProductInstallationCases.tsx`, `src/api/productApi.ts`, `pages/admin/ProductManager.tsx`, `pages/ProductDetail.tsx`, `supabase_bootstrap_schema.sql`, `scripts/installation-cases.test.cjs`(신규 테스트)
- 검증: 타입 검사, 빌드, 테스트 15개(신규 5 + 기존 설치사진 10) 통과. 로컬에서 상품 상세 로드와 콘솔 오류 없음을 확인했습니다.
- 미검증: 관리자에서 실제 업로드와 저장, 이미지와 패키지 카드가 올라간 실제 화면(모바일 포함)은 아직 보지 못했습니다.

## 2) 이미지 소재 작업 (홈 설치 사례 / 상세 이미지용)
- 홈 설치 사례용 대표이미지 일러스트 4종(사무실, 행사 부스, 교육장, 주거·휴게)을 PC 1600×1000과 모바일 1200×900으로 만들었습니다(`banner-work/review-thumbs/`). 이후 방향이 "실사 연출 이미지"로 바뀌어 임시 소재로만 둡니다.
- 직접 찍은 현장 사진은 정리가 덜 돼 쓰기 어렵다고 하셔서, 이미지 AI용 프롬프트를 작성했습니다. 사진 없이 새로 생성하는 프롬프트 4종과, 소형 교세라 복사기를 책상·PC 옆에 두는 장면으로 바꾸는 프롬프트입니다. 이미지 생성 자체는 외부 도구에서 하셔야 하고, 결과물을 받으면 규격에 맞게 마무리하기로 했습니다.
- 운영 원칙을 정했습니다. 패키지 페이지에는 연출·실사진을 함께 쓰되 연출은 표기하고, 개별 상품 페이지는 이미지 아래에 연출 문구를 붙여 패키지로 안내합니다.

## 3) 환경
- LAN 개발 서버를 열었습니다(`localhost:3000`, 같은 네트워크 `192.168.35.242:3000`). 실행 설정용 `.claude/launch.json`이 새로 생겼습니다.

## 남은 이슈 / 확인 필요
- 변경 사항을 아직 커밋하지 않았습니다.
- 이미지 문구는 모든 상품에 고정으로 붙습니다. 실제 납품 사진을 올리는 상품이 생기면 상품별로 켜고 끄는 방식으로 바꿔야 합니다.
- 패키지 카드는 페이지를 연 뒤 늦게 불러와서 문구가 짧은 것에서 긴 것으로 바뀔 수 있습니다.
- 상품 상세를 열 때마다 패키지 목록을 한 번 읽습니다. 패키지가 수백 개로 늘면 서버 조회 방식으로 바꿔야 합니다.
- "상세정보 준비중" 박스는 올린 이미지만 기준으로 숨깁니다. 패키지 카드만 있는 상품은 박스가 보입니다.
