## 2) 관리자 이미지 자르기 (사진 앱의 가위 자르기 방식)
- 대표 이미지와 추가 이미지를 올리기 전에 **자르기 창**이 뜹니다. 사진 전체 위에 사각형을 놓고 끌어서 옮기거나 모서리와 변을 당겨 원하는 부분만 자릅니다.
- 비율: 자유(기본), 4:3, 1:1, 16:10, 3:4. 「원본 그대로 올리기」와 「취소」도 있습니다. 가로 최대 2000px로 줄이고 PNG는 투명 배경을 유지합니다.
- 추가 이미지는 여러 장을 고르면 사진마다 자르기 창이 차례로 뜹니다. 외부 라이브러리 없이 직접 만들었습니다.
- 처음에 사진이 빈 틀로 뜬 문제는 StrictMode에서 사진 주소가 먼저 폐기되던 버그였고 고쳤습니다.
- 파일: `components/admin/ImageCropDialog.tsx`(신규)

## 3) 패키지 상세 구조 정리 (중복 제거 + 사진 태그 연동)
- 같은 상품이 세 곳에서 서로 다르게 보이던 문제를 정리했습니다. **"한눈에 보는 패키지 구성"과 접이식 "구성 변경"을 "패키지 구성과 수량" 하나로 합쳤고**, 사진 아래 "사진 속 렌탈 상품" 카드 목록은 없앴습니다.
- **"패키지 포함 여부"(기본 포함/추가 선택/연출 참고) 개념을 없앴습니다.** 태그한 상품은 모두 구성품입니다. 팝업과 목록의 뱃지도 삭제했습니다.
- 관리자: 상품을 새로 태그하면 기본 필수 구성품에 자동 추가(수량 = 태그 개수), 마지막 태그를 지우면 구성품에서도 빠집니다. 기존 항목과 수량은 유지합니다. **"사진 태그로 덮어쓰기"** 버튼으로 기존 목록을 태그 상품 전체로 바꿀 수 있습니다(확인창 있음, 같은 이름은 수량 유지).
- 사진 위 상품 표시: 평소에는 보이지 않고 **마우스를 올리면 손 모양 커서와 손 아이콘**이 나타납니다. 눌러서 열린 안내가 있는 동안 눌린 표시는 숨겨지고, 사진 빈 곳이나 X, Esc로 닫습니다. 터치 화면에서는 올릴 수 없어서 작은 아이콘을 항상 보이게 했습니다.
- 운영 DB 확인: 패키지 12개 모두 "기본 포함" 태그가 없어서 **기존 구성품은 그대로**입니다. 태그를 새로 찍거나 지울 때, 덮어쓰기를 누를 때만 바뀝니다.
- 파일: `pages/ProductDetail.tsx`, `components/products/PackageDetailSections.tsx`, `PackageInstallationGallery.tsx/.css`, `PackageDetail.css`, `components/admin/PackageInstallationEditor.tsx`, `pages/admin/ProductManager.tsx`, `src/utils/installationScenes.ts`
