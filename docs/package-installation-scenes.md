# 간편패키지 설치사진 · 상품 태그

## 활성화

1. 이 프로젝트에 연결된 Supabase의 SQL Editor에서 저장소 루트의 `add_product_installation_scenes.sql`을 한 번 실행합니다. 기존 상품을 수정하거나 삭제하지 않고 `products.installation_scenes` 항목을 추가합니다.
2. 관리자 → 상품 관리에서 간편패키지 상품을 편집합니다.
3. **설치사진 · 상품 태그**에서 사진을 업로드하거나 **대표 이미지 가져오기**를 선택합니다. 기존 이미지 주소로 추가할 수도 있습니다.
4. 사진 속 물건의 위치를 클릭하고 등록된 상품을 검색해 연결합니다.
5. **기본 포함 / 추가 선택 / 연출 참고 · 별도 확인**을 실제 패키지 구성에 맞춰 선택합니다. 최초 선택값은 연출 참고입니다.
6. 상품을 저장한 뒤 해당 패키지 상세페이지에서 확인합니다.

사진이 없으면 기존 대표 이미지가 표시됩니다. 실제 설치사진과 상품 연결 정보는 관리자가 입력해야 합니다. 현재 상세설명에 들어 있는 사진은 자동 이전하지 않습니다.

## 편집 동작

- 사진 최대 12장, 사진별 상품 태그 최대 30개.
- 업로드는 10MB 이하 JPG·PNG·WebP를 지원합니다.
- 좌표는 사진 원본의 가로·세로 비율(0–100%)로 저장됩니다. 원본을 자르지 않고 표시하여 화면 크기가 변해도 위치가 유지됩니다.
- 키보드로는 **중앙에 상품 태그 추가** 후 가로·세로 위치를 조절할 수 있습니다.
- 업로드 중이거나 새 태그의 상품을 선택하지 않은 경우 전체 저장이 잠깁니다. 상품 선택 또는 태그 추가 취소 후 저장합니다.
- 사진을 바꾸려면 해당 사진을 삭제하고 새 사진을 등록합니다. 기존 위치를 다른 사진에 잘못 적용하지 않기 위한 방식입니다.
- 사진 삭제는 편집 중인 상품의 연결 정보만 제거합니다. 원본 스토리지 파일은 자동 삭제하지 않습니다.
- 기본 포함 표시는 관리자가 정한 기본 구성 기준이며, 고객이 견적에서 변경한 수량에 따라 자동 갱신되는 표시는 아닙니다.

## 고객 화면

- 설치사진 위 + 버튼을 누르면 상품 사진·상품명·포함 여부·상품 상세 링크를 표시합니다.
- 모바일은 선택 상품을 사진 아래에 표시합니다.
- 사진 아래 상품 목록에서도 상품 상세로 이동할 수 있습니다.
- 연결 상품이 삭제된 경우 링크를 숨기고 현재 확인할 수 없는 상품으로 표시합니다.
- 상품 조회가 실패하면 다시 시도할 수 있습니다.
- 상품명·대표 사진은 연결 상품의 현재 데이터를 사용하며 가격은 표시하지 않습니다.

## DB 호환성

새 항목이 없는 DB에서도 설치사진이 없는 상품은 저장할 수 있습니다. 설치사진이 있는 상품의 저장은 DB 업데이트 안내와 함께 실패하고 입력값을 유지합니다. 사진을 조용히 버린 채 저장하지 않습니다.

일반 상품·부가서비스로 저장할 때는 설치사진 데이터를 비웁니다. 새 프로젝트 초기 스키마에는 컬럼을 포함했으며, 기존 프로젝트에는 전용 SQL 파일을 적용합니다.

## 검증

- `node --test scripts/installation-scenes.test.cjs`: 저장·삭제·DB 컬럼 부재·입력 검증·기존 대표 이미지 유지·연결 상품 조회에 대한 회귀 테스트. DB는 메모리 모형을 사용하며 실제 데이터를 쓰지 않습니다.
- `node node_modules/typescript/bin/tsc --noEmit`: 타입 검사.
- `node node_modules/vite/bin/vite.js build`: 프론트엔드 빌드.

실제 DB 저장과 브라우저 클릭 검증은 SQL 적용 후 필요합니다. 375px/768px/1280px 화면에서 사진 가장자리 태그, 긴 상품명, 사진 전환, Escape 닫기, 이미지 로드 실패를 확인합니다.

## 간편패키지 전용 상세 화면

간편패키지(catalog_type=package)는 전용 제목과 탐색 메뉴, 설치사진, 구성품 카드, 접어서 펼치는 구성 변경, 이용 안내·FAQ 순서로 표시됩니다. 일반 상품은 기존 상세 레이아웃을 사용합니다. 기존 긴 상세설명은 하단의 **상세 사양과 기존 안내 보기**에 보존됩니다.

구성품 카드와 견적 요약에는 현재 선택한 수량이 표시됩니다. 모바일에서는 하단 견적 바에서 요약을 확인하고 **구성 변경하기**로 수량과 조합 옵션을 조정할 수 있습니다. 인원 수를 임의로 추천하지 않으며, 대여 기간과 설치 장소 입력은 기존 견적 접수 흐름을 사용합니다.
